# New feature briefs

- [`indexer-endpoint-resolver-spec.md`](indexer-endpoint-resolver-spec.md) — accepted specification for continuously measured indexer reachability, endpoint tiers, and automatic failover.
- [`network-egress-control-spec.md`](network-egress-control-spec.md) — draft specification for operator-controlled egress: VPN lifecycle in Control, per-indexer proxy routing, and the placement of Trawl.

Briefs describe proposed or agreed feature direction ahead of delivery. A brief is not evidence that
anything is implemented; confirm against code, contracts, and tests before relying on it. Accepted briefs
may be ahead of the runtime, and drafts carry no commitment at all.
