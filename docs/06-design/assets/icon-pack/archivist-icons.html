Icon Pack

One stroke language across Library, Player, Catalogue and Control. 180 icons, one drawing per concept, replacing the 108 emoji and Unicode glyphs the applications currently render through the host font — and the four competing icon systems that grew up alongside them.

Optical compensation

Stroke weight grows as the icon shrinks — 3 units at 40px and above, 3.6 at 24, 5 below — so density stays constant. Shown at 16, 20, 24, 32 and 48px.
