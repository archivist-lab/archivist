# Archivist Media Icons

> **Superseded by [`../icon-pack/`](../icon-pack/).** These are 200x200
> gradient-filled brand tiles, not interface icons, and their treatment conflicts
> with the monoline language the pack is built on. The module identity they carry
> now lives in the pack: `film`, `series`, `music`, `artwork` (aliased as
> `photos`), `channels` and `collections`. Kept here for comparison; nothing
> imports them.

SVG icon set derived from the visual system in `spinner.svg`.

## Files

- `films.svg` — cyan `#00D4FF`
- `tv.svg` — purple `#9B59B6`
- `music.svg` — pink `#FF2D78`
- `photos.svg` — yellow `#F1C40F`
- `channels.svg` — orange `#E67E22`
- `collections.svg` — green `#2ECC71`

All icons use a `0 0 200 200` viewBox and can be resized without modification.
